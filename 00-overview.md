## Cross-cutting themes

1. **Claude Code is the central productivity tool.** Specific workflows, plugins (Ralph Wiggum, Cartographer, /simplify, /prompt), and integration patterns recur across dozens of bookmarks. Knowing how Claude Code is being used in 2026 is essential context for any AI engineering work.

2. **Agentic loops are mainstream.** "Ralph loops", droid+GitHub-issues integration, multi-instance orchestration, plan-mode-into-Codex pipelines — no longer experimental.

3. **MCP (Model Context Protocol) is the integration glue.** Several bookmarks reference the MCP 2026-07-28 spec, MCP servers from Google for Gmail/Drive/Calendar, and using MCP to connect tools to AI workflows.

4. **"Best practice is no longer human-in-the-loop, it's human-as-reviewer."** Multiple Anthropic engineers, indie operators, and enterprise leads converge on: set up agentic loops, kick them off, sleep, review the output.

5. **Boring infrastructure wins.** Anti-Kubernetes-for-its-own-sake, pro-ECS, pro-Hetzner-VPS. Multiple bookmarks describing real companies running on minimal infra.

6. **The leverage hierarchy is shifting.** Naval's framing: labor → capital → code/media → **AI**. AI compounds existing leverage, doesn't replace it.

## What this corpus is NOT

- A research library — mostly tweets, not papers

Use it as **flavor and orientation**, not as ground truth.
